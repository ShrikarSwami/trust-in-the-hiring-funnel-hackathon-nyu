# Trust in the Hiring Funnel Hackathon @ NYU

Project repo for the "Trust in the Hiring Funnel Hackathon @ NYU" (Sep 19, 2026, NYU MakerSpace,
Brooklyn), co-hosted by localhost:nyc, Integral Recruiting (IRD), and NYU.

Generative AI has broken trust on both sides of hiring: recruiters can't tell which applicants
are real, and candidates can't tell which employers reaching out are real. This project attacks
one (or both) sides of that problem. See [docs/event-brief.md](docs/event-brief.md) for the full
challenge brief.
